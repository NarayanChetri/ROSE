### 🗜️ Archive Powerhouse
- **Multi-Format Extraction & Browsing**: Support for **ZIP, RAR, 7-Zip (`.7z`), TAR, GZ, TGZ, BZ2, XZ, ISO, APK, XAPK, and APKS**.
- **In-Archive File Explorer**: Browse folders and inspect files inside archives without extracting everything first.
- **APK Archive Inspector**: View dex, resources, and assets inside APKs directly.
- **Encrypted Archives**: Create password-protected ZIPs (AES-256 / ZipCrypto) and extract password-secured archives.
- **Selective Extraction**: Extract individual files or complete archives anywhere on your device.

## 📋 Requirements & Permissions

<p align="center">
### Minimum Requirements
- **OS**: Android 8.0 (Oreo) or higher (API 24+)
- **Storage**: Storage permission (All Files Access on Android 11+)
- **Shizuku** *(Optional)*: Needed only if you want to access `Android/data` and `Android/obb` without root.

### Permissions Explained
| Permission | Why ROSE Needs It |
| :--- | :--- |
| **All Files Access (`MANAGE_EXTERNAL_STORAGE`)** | Required by Android to read, write, copy, and organize files on your device. |
| **Shizuku** | Optional. Grants elevated access to restricted system folders without rooting your phone. |
| **Foreground Service** | Keeps large file operations (compressing, extracting, moving) running reliably without getting killed by Android. |

## 🚀 Installation
## 🚀 How to Install & Troubleshooting

1. Download the latest APK from the Releases page.
2. Install the APK.
3. (Optional) Connect Shizuku for Android/data and Android/obb access.
4. Enjoy.
### Standard Installation
1. Download the latest `.apk` from **[GitHub Releases](https://github.com/NarayanChetri/ROSE/releases/latest)**.
2. Open your device's Downloads folder and tap the APK file.
3. Follow the on-screen prompt to install.

### Troubleshooting "Blocked by Play Protect" or "Unrecognized App"
Because ROSE is open source and distributed directly via GitHub rather than Google Play Store, Android's Play Protect might show a warning like *"Unrecognized app"* or *"Unknown publisher"*:
- Tap **More details** (or **Advanced**).
- Tap **Install anyway**.
- *ROSE is 100% open source and contains zero malicious code or ads.*
